# Landing page images

Put your photos in this folder using the exact filenames below. The page picks them up automatically —
until a file exists, a labelled placeholder is shown in its place.

- Images are cropped to fit with `object-fit: cover`, so keep the main subject near the centre.
- Export at the recommended size (or larger, same shape). JPG at ~80% quality keeps pages fast.
- Using a different name or format (e.g. `.webp`)? Update the `file` value in `src/config/landingImages.ts`.
- Update each image's `alt` text in the same file so it describes your actual photo.
